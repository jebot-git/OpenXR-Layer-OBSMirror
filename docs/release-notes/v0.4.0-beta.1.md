# v0.4.0-beta.1 — Vulkan capture

First Vulkan release of the jebot-git fork of OpenXR OBS Mirror.

- Windows: Vulkan OpenXR capture through asynchronous host readback into the
  existing D3D11 compositor, alongside the existing D3D11/D3D12 and OpenVR paths.
- Vulkan color arrays, mip-zero capture, MSAA resolves, and static overlays.
- Transfer tests exercise real Vulkan operations and support Khronos
  synchronization validation.

Vulkan capture uses host readback, which adds bandwidth cost and can add
recording latency. These are experimental builds; live headset interoperability
requires testing on the application's OpenXR runtime. See `docs/VULKAN.md`.

The Windows package includes the layer, OBS plugin for OBS 32.2.2, Control
Center, and installation scripts. Windows binaries are unsigned.
